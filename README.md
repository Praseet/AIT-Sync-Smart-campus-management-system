# 🎓 AIT-Sync Smart Campus Management System

A comprehensive smart campus management system built to streamline campus operations, enhance student experience, and improve administrative efficiency.

## ✨ Features

- **Student Management** - Track student information, attendance, and academic records
- **Course Management** - Manage courses, schedules, and assignments
- **AI-Powered Insights** - Leverage AI for analytics and recommendations
- **Real-time Notifications** - Stay updated with campus activities
- **Resource Management** - Efficiently manage campus resources and facilities

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn package manager
- Gemini API key

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/yourusername/AIT-Sync-Smart-campus-management-system.git
   cd AIT-Sync-Smart-campus-management-system
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Configure environment variables:

   - Create a `.env.local` file in the root directory
   - Add your Gemini API key:

     ```
     GEMINI_API_KEY=your_api_key_here
     ```

4. Run the development server:

   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser

## 🛠️ Tech Stack

- **Frontend**: React/Next.js
- **AI Integration**: Google Gemini API
- **Styling**: Tailwind CSS / Material-UI
- **State Management**: React Context / Redux
